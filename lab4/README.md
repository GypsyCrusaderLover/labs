# Лабораторная работа №4: Рефакторинг и расширенные команды списка задач

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Описание обновлений
1. Выполнен рефакторинг кода:
   - Внедрены константы `InitialCapacity`, `StatusDone`, `StatusNotDone`;
   - Вынесены отдельные специализированные методы: `ProcessHelp`, `ProcessProfile`, `ProcessAdd`, `ProcessView`, `ProcessDone`, `ProcessDelete`, `ProcessUpdate`, `EnsureCapacity`.
2. Добавлены синхронизированные параллельные массивы:
   - `statuses` (`bool[]`) — состояние выполнения задачи;
   - `dates` (`DateTime[]`) — дата создания или изменения задачи.
3. Расширен функционал команд:
   - `add` — фиксирует статус `false` и текущую дату;
   - `view` — вывод в формате: `<индекс> <текст задачи> <сделано/не сделано> <дата>`;
   - `done <idx>` — помечает задачу выполненной и обновляет дату;
   - `delete <idx>` — удаляет элемент по индексу со сдвигом элементов влево;
   - `update <idx> "new_text"` — обновляет текст и дату задачи.
