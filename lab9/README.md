# Лабораторная работа №9: Коллекции, итераторы, индексаторы и перечисления в TodoListApp

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Архитектурные особенности
1. **Коллекция `List<TodoItem>` в `TodoList`**:
   - Приватный список `_items` взамен массива фиксированной длины;
   - Удалён метод расширения `IncreaseArray`;
   - Реализован индексатор `public TodoItem this[int index]`;
   - Реализован итератор с оператором `yield return` для поддержки `foreach`.
2. **Перечисление статусов `TodoStatus`**:
   - Значения: `NotStarted`, `InProgress`, `Completed`, `Postponed`, `Failed`.
   - В `TodoItem` свойство `Status` заменило булево поле `IsDone`.
3. **Команда `status <idx> <status>`**:
   - Заменила устаревшую команду `done`;
   - Поддерживает установку любого из 5 статусов и парсинг через `Enum.TryParse<TodoStatus>()`.
4. **Обновление `FileManager`**:
   - Сериализация и десериализация текстового представления статусов в CSV.
