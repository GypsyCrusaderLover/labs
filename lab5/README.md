# Лабораторная работа №5: Поддержка флагов команд и многострочный ввод в TodoListApp

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Новые возможности программы
1. **Многострочный ввод для команды `add`**:
   - Флаги `--multiline` или `-m`.
   - Ввод продолжается построчно до ввода стоп-маркера `!end`.
   - Строки объединяются через `\n` и сохраняются как единый текст.
2. **Гибкие флаги для команды `view`**:
   - Фильтры: `--all` (`-a`), `--done` (`-d`), `--undone` (`-u`).
   - Колонки: `--index` (`-i`), `--status` (`-s`), `--date` (`-t`).
   - Поддержка комбинаций коротких флагов (например: `-is`, `-aut`).
3. **Новая команда `read <idx>`**:
   - Выводит полный текст задачи с сохранением структуры строк и переносов, а также статус и дату.
