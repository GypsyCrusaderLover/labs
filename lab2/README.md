## Описание работы
1. Создано консольное приложение C# `TodoListApp`.
2. Настроен файл `.gitignore` с исключением папок `bin/`, `obj/`, `.vs/`.
3. Реализован ввод имени, фамилии и года рождения пользователя через `Console.ReadLine()`.

5. Реализован вывод приветствия и информации о добавленном пользователе в формате:
   `Добавлен пользователь <Имя> <Фамилия>, возраст - <возраст>`
