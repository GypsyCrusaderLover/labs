# Лабораторная работа №8: Файловое хранилище данных в TodoListApp

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Архитектурные особенности
1. **Класс `FileManager`**:
   - `EnsureDataDirectory(string dirPath)` — проверка и создание целевой директории;
   - `SaveProfile` / `LoadProfile` — сериализация/десериализация профиля в текстовый файл `profile.txt`;
   - `SaveTodos` / `LoadTodos` — сохранение и чтение списка задач в формате CSV (`todo.csv`).
2. **Формат CSV и экранирование**:
   - Заголовки: `Index;Text;IsDone;LastUpdate`;
   - Поддержка кавычек `\"` и экранирование переносов строк `\n` <-> `\\n`.
3. **Автосохранение и восстановление**:
   - Автоматическая загрузка данных при старте приложения;
   - Автоматическое сохранение при операциях добавления, выполнения, удаления и обновления.
