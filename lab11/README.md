# Лабораторная работа №11: Многопользовательский режим и профили в TodoListApp

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Архитектурные особенности
1. **Расширение модели `Profile`**:
   - Добавлены свойства `Id` (`Guid`), `Login`, `Password`;
   - Все профили сохраняются в общем CSV-файле `profile.csv` в формате:
     `Id;Login;Password;FirstName;LastName;BirthYear`.
2. **Многопользовательское разделение данных**:
   - В `AppInfo` хранится список профилей и `CurrentProfileId`;
   - Задачи каждого пользователя изолированы и хранятся в индивидуальном файле: `todos_<Id>.csv`;
   - Доступ к задачам (`add`, `view`, `read`, `status`, `update`, `delete`) ограничен задачами активного профиля.
3. **Аутентификация и смена профиля**:
   - Диалог при старте программы: `Войти в существующий профиль? [y/n]`;
   - Команда `profile --out` (`profile -o`) выполняет выход из текущей сессии;
   - При смене пользователя стеки `UndoStack` и `RedoStack` гарантированно сбрасываются.
