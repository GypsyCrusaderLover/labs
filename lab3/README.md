# Лабораторная работа №3: Интерактивный список задач TodoListApp

## Выполнили
Лукьяненко Даниил, Мироненко Данил, группа 3831.9

## Новые возможности программы
1. Реализован бесконечный интерактивный цикл обработки пользовательских команд.
2. Поддерживаются следующие команды:
   - `help` — вывод списка всех доступных команд с кратким описанием;
   - `profile` — вывод данных пользователя в формате: `<Имя> <Фамилия>, <Год рождения>`;
   - `add "текст задачи"` — добавление новой задачи с извлечением текста через `String.Split`;
   - `view` — вывод всех непустых задач из массива;
   - `exit` — завершение работы программы.
3. Реализовано динамическое расширение массива `todos`:
   - Начальный размер массива равен 2 элементам;
   - При заполнении выделяется новый массив удвоенной длины (`todos.Length * 2`), элементы копируются в цикле.
